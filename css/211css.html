Why Use Flexbox?

Flexbox provides a convenient way to distribute space between elements and align content inside containers.

✓
Flexible element sizing
✓
Automatic wrapping
✓
Simple horizontal and vertical alignment
✓
Responsive layouts with fewer media queries

Flex Grow

Allows flex items to expand and share available space inside their container.

Flex Wrap

Allows items to move onto additional rows when there is not enough horizontal space.
