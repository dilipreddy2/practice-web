Unit Examples

Relative Unit Demonstration

This box uses em units. 2em padding
This box uses rem units. 1.5rem
This box uses vw units. 50vw
This box uses vh units. 20vh
This box uses percentage units. 70%
How it works:

em — relative to the font size of the element or its parent.

rem — relative to the root html font size.

vw — relative to the viewport width. 50vw means 50% of the browser width.

vh — relative to the viewport height. 20vh means 20% of the browser height.

% — relative to the size of the parent element.
