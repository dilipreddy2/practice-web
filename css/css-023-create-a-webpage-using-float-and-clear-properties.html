CSS Float and Clear

Demonstration of floating an image to the left and clearing the float using CSS.

Float Example

Float Image to Left

This paragraph contains text beside the image. The image is floated to the left, allowing the text to flow around it. The CSS float: left; property moves the image to the left side and allows surrounding content to flow beside it.

Clear Example:
This section uses clear: both; so it appears below the floated image.
How it works:

float: left; moves the image to the left and allows text to wrap around it.

clear: both; prevents the element from appearing beside any floated elements and moves it below them.
