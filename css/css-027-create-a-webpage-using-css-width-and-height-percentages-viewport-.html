CSS WIDTH & HEIGHT

CSS Width and Height Units

Demonstration of fixed, percentage, viewport, and automatic width and height units.

Unit Examples

Width and Height Units

Width: 300px | Height: 100px px
Width: 70% %
Width: 50vw vw
Height: 20vh vh
Width and Height: Auto auto
How it works:

px — fixed pixel size.

% — size relative to the parent element.

vw — viewport width. 50vw means 50% of the browser window width.

vh — viewport height. 20vh means 20% of the browser window height.

auto — allows the browser to calculate the size automatically.
